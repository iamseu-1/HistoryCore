# 나무마크 문법과 그리기 모델 1

설계 5-6 · 5-8. 해석기는 `crates/namumark`(옛 Dart 해석기를 옮김 — 옛 검사가 정답지). 이 문서가 앱 · `library_view`와의 약속이다.

블록 매크로(목차 · include · embed · 대문 · 연표 띠)는 **줄 하나 전체**일 때만 블록이다.

## 인라인

| 문법 | 뜻 |
| --- | --- |
| `'''굵게'''` `''기울임''` `__밑줄__` `~~취소~~` `--취소--` `^^위^^` `,,아래,,` `'''''굵은 기울임'''''` | 글꼴(한 줄 안에서 닫혀야 한다) |
| `{{{+2 글}}}` (-5..+5) · `{{{#색 글}}}` · `{{{날 것}}}` | 크기 · 색(글자만) · 날 것 |
| `[[제목]]` `[[제목\|보일 글]]` `[[제목#앵커]]` `[[#앵커]]` `[[/하위]]` `[[../]]` | 링크(같은 문서 · 상대) |
| `[[분류:이름]]` · `[[:분류:이름]]` | 분류 달기(본문에서 빠진다, 첫 것이 집) · 분류 문서로의 링크 |
| `[[파일:이름\|width=320&align=center]]` | 그림 |
| `[[https://…\|글]]` | 바깥 링크 |
| `[[연표:<항목ID>\|글]]` | 연표 항목 링크(설계 7-1) |
| `[* 글]` · `[*이름 글]` · `[*이름]` | 각주 · 이름 붙인 각주 · 그 재사용 |
| `[br]` `[date]` `[age(…)]` `[dday(…)]` `[anchor(이름)]` `[ruby(글, ruby=읽기)]` | 매크로 |
| `\` | 다음 글자 하나를 글자로 |
| `@이름@` · `@이름=기본값@` | 틀 인자(틀 안에서만) |

닫히지 않은 표식은 글자로 남는다. 이름공간 접두어: `문서` `분류` `틀` `파일` `대문` `연표` `字` `책`.

## 틀 펼치기

- `[include(틀:이름, 인자=값)]`는 저장할 때 펼쳐 모델에 굳힌다. 틀 원문의 `@이름@` · `@이름=기본값@`을 **해석하기 전에** 인자 글로 채운다(인자가 없고 기본값도 없으면 빈 글).
- 틀이 넘겨주기면 **한 번** 따라간다(이름 바꾼 틀). 두 번은 따르지 않는다(`missing`).
- 멈춤: 펼치는 사슬에 이미 있는 틀(`cycle`) · 깊이 8(`too_deep`) · 한 문서에서 2,000번(`too_many`) · 한 문서에서 읽은 틀 원문과 채운 글이 합쳐 8 MiB를 넘음(`too_large` — 인자를 여러 번 넘겨 단마다 글이 불어나는 틀) · 없는 틀(`missing`). 그 자리는 `blocks`가 빈 `template` 블록.
- 한 번 그리는 동안 같은 틀은 한 번만 읽는다.
- 틀의 각주는 문서의 각주와 함께 **그린 차례로** 번호를 다시 매긴다. 틀의 분류는 `template_categories`(집은 본문 첫 분류).
- `templates`는 펼치려 한 틀 전부(없던 것 · 넘겨주기 대상 포함) — 그 틀이 생기거나 바뀌면 이 문서를 다시 그린다(설계 5-5).

## 한계

중첩 깊이 32 · 짝 찾기 훑기 예산 `64 × 원문 바이트 + 1,000,000`(넘으면 남은 표식은 글자 — 여러 줄 `{{{` 블록은 닫는 줄까지만 센다. 펼친 틀은 예산을 따로 받지 않고 `1,000,000 + 64 × 채운 틀 글 바이트` 하나를 나눠 쓴다) · 줄 안 매크로 · `@인자@` 찾기 창 256바이트 · 표 가로 합치기 64 · 세로 합치기 256.

## 그리기 모델 JSON(판 1)

```
{ "version": 1, "redirect": 주소|null, "blocks": [블록], "footnotes": [{"n", "name", "inl": [인라인]}],
  "sections": [{"index", "level", "number", "title", "start", "end"}],
  "categories": [글], "template_categories": [글], "templates": ["틀:이름"] }
```
- 주소: `{"ns", "key", "anchor"}`. 같은 문서 안 링크는 `ns` · `key`가 빈 글.
- `sections[].start/end`: 줄끝을 `\n`으로 맞춘 원문의 **UTF-16 칸** 위치(Dart 글 위치와 같다). 문단 편집은 이 범위를 자른다.
- 링크가 있는 문서인지는 굳히지 않는다 — 볼 때 `titles.exist`로 묻는다(P2-3).
